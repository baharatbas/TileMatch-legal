| Privacy Policy | `privacy.html` |

Hosted with GitHub Pages: https://baharatbas.github.io/TileMatch-legal/

- Add `#en` or `#tr` to a link to open a specific language, e.g. `privacy.html#tr`.
- `app-ads.txt` contains the AdMob seller line. Google reads it from the root of the website domain you list
  in your store listing, so it only takes effect if this site is served from the root of that domain.
- These pages are a plain-language template, not legal advice. Have them reviewed before you rely on them.
